# Code availability template

## English

All custom analysis code used to generate the reported LEiDA, longitudinal mixed-effects, prespecified cross-sectional, imaging-transcriptomic, spatial-permutation and enrichment results is available at **[GitHub repository URL]**. A versioned archive of the code used for this manuscript is available at **[Zenodo DOI]**. The repository includes an environment specification, documented analysis order and expected input/output structure. Figure-generation code is maintained separately from the inferential analysis code. Code for rs-fMRI preprocessing is provided as the corresponding DPABI batch configuration. Participant-level data are available subject to the ethical approval and data-sharing conditions described in the Data Availability statement.
